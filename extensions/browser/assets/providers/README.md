# Provider marks

The Claude, Codex (OpenAI) and OpenCode marks are used only to identify which product an agent is running on. They are trademarks of their owners; M9R is not affiliated with or endorsed by them. Source: the open-source LobeHub icon set (`@lobehub/icons-static-svg`). The presence overlay renders each mark white on the provider's colour badge and falls back to a letter if an image cannot load.
