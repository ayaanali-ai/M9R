Chrome’s site permission covers the entire site, not just the approved path. M9R will still enforce the grant’s listed actions, path, and expiry locally. The agent may read visible page content and use the approved page controls; passwords and other sensitive fields remain blocked.

What browser access means

When you run an M9R browser task, requested page text, URLs, and action data (including text you ask an agent to type into ordinary fields) go to the M9R broker on this computer and may be sent to the selected agent/provider and authorized M9R collaborators. Password, hidden, payment-card, and one-time-code fields are blocked by targeted checks, but visible pages can still contain sensitive information. No page data is sent merely by granting browser permission.
