# Store permission justifications

| Permission or access | What it is used for in the code | Scope and caveat |
|---|---|---|
| `tabs` | Read tab URLs to enforce approved agent scopes; find the active tab; create and update M9R-managed tabs; open the one-time microphone setup page. | Tab URLs are sensitive; M9R uses them for scope checks and named-tab state. |
| `scripting` | Inject the extension's packaged overlay and page-action code into ordinary websites. | No remote code is fetched or evaluated; all injected files ship in the package. |
| `alarms` | Wake the service worker periodically to keep the connection to the local M9R app alive. | Connection maintenance only. |
| `storage` | Keep named-tab mappings across service-worker restarts, the pill's position and open state, motion preferences, hidden message previews, and a short local log of Alt+M / Alt+N presses for troubleshooting. | No page text or form values are stored by this UI; the key log holds no typed text and can be cleared. |
| `nativeMessaging` | Send a bounded, validated pointer-and-click request to the separately installed M9R native input host for visible shared Chrome tabs. The host drives the foreground browser window with Windows native input and returns pointer progress and a result. | The packaged development build permits only M9R's fixed extension ID. Native input is limited to the active, visible Chrome tab and an approved page-action plan; there is no synthetic-click fallback. A Chrome Web Store package needs its own verified store extension ID enrolled in the host manifest before this path can activate. |
| Required `http://*/*`, `https://*/*` | Show the overlay and enable governed browser actions on ordinary websites, including localhost. | Chrome requests this broad access when the extension is installed or updated. Chrome may still withhold or revoke it; M9R enforces approved agent scopes and consequential-action approvals separately. |
| `web_accessible_resources`: `pill-next/*` (the one pill's page and scripts), `assets/providers/*.svg` (http/https pages) | The pill (agents, approvals and message box) is an extension page shown in a frame on the page, so a website's own scripts cannot read what the owner types. The provider badges are the small agent icons on cursors. | Only the pill bundle folder and the badge icons are exposed; no other pages. The frames accept commands only with a per-tab secret that the extension's own content script registers. |
| Microphone (web API, not a manifest permission) | Push-to-talk while Alt+M is held, in the pill's frame; turned on once from an extension page. | Speech is recognised by Chrome's speech service; the extension never receives or stores audio. |

| Optional `debugger` (requested only when the owner turns on quiet mode) | Lets agent clicks reach a page without moving the owner's mouse or taking their window. Only a fixed set of input commands is ever sent; Chrome shows its own "started debugging this browser" banner while attached. | Never granted at install; the owner opts in from the extension popup and can turn it off, which removes the permission. |

Not requested at install: cookies, history, downloads, or `activeTab`. No remote code is loaded. Recheck this table against the packed manifest and the code immediately before every submission.
