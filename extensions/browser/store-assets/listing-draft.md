# Chrome Web Store listing draft

**Name:** M9R Web Presence

**Short description:** Connect your approved M9R agents to browser pages you choose.

**Detailed description:**

M9R Web Presence links your browser to the M9R service running on your computer. When you explicitly grant a site and start an M9R browser task, connected agents can work through the approved browser workflow while M9R displays their presence on the page.

- Grant access site by site from the browser owner flow.
- See connected-agent presence markers on a page.
- Let an authorized M9R task open a page, read requested page text, click an eligible control, or type supplied text.
- Keep the extension's action code packaged locally; the extension does not download executable page-action code.
- Use the local M9R broker; this extension is not a standalone agent.

Page text and requested action results are sent to the local M9R broker and may be shared with the agent/provider or authorized collaborators selected in M9R. Chrome's site permission is origin-wide; M9R also enforces its own approved action, path, and expiry. Targeted password, hidden, payment-card, and one-time-code fields are blocked, but visible page content and ordinary fields can still contain sensitive information.
