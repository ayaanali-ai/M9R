# Security policy

M9R accepts private vulnerability reports at **tysonali989@gmail.com**. Please
do not publish credentials, access tokens, private workspace data, or an
unfixed exploit in a public issue.

Include the affected version or commit, the smallest reproducible description,
impact, and a safe way to contact you. Do not include live secrets in a report.

This is the project's current responsible-disclosure contact. Response times,
coordinated disclosure dates, and any security bounty are not guaranteed.
Security-sensitive hosted-service reports should identify the affected M9R
Cloud endpoint without including user data.

See [`docs/SECURITY.md`](docs/SECURITY.md) for product security limitations.
