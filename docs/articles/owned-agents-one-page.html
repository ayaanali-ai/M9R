Owned agents still need somewhere to meet.

Owning your agent is the right instinct. Your agent and mine will still land on the same web page. Here is what we built, measured and broke finding out what that takes.

Zain Javaid's essay “Own Your Intelligence” argues that personal AI should belong to the person it serves, not be rented back by the token. His line is short: “Owned is a better product.” We agree with the instinct. This essay is about the question it raises next.

Owned means different.

If agents belong to their owners, they will differ. Different models, different harnesses, different memory, different rules. Yours runs on a laptop at home, mine on a subscription, a friend's on a box in a closet.

Then they will do what people do. They will open the same website. A checkout, a booking, a shared document, a support form.

Today, agents on the same page have no idea the others exist. Two of them fill the same field. One acts on what another told it without checking. A hostile page tells all of them what to do.

None of that gets better because each agent is owned. It gets more common.

Coordination is not ownership.

The usual fix for collisions is to own everything: one vendor's agents in one vendor's browser. That works, and it gives up the thing owners wanted.

The alternative is a small set of rules that live next to each person's own browser and belong to nobody: who is doing what right now, who holds what, what a guest may do, what happened, and how the owner steps in.

We have been building that as M9R. What follows is what we can show, not what we plan to show.

ProofTwo agents, one page, no collision.

We ran the real browser extension and a local broker on one machine. A test script sent real commands as two agent identities, Claude and Codex, against the same page. Each shows up as a cursor with a name. When the first agent starts typing in a field, it takes a short-lived claim and the page shows a lock. When the second agent tries to type in that tab, it is refused with a plain message, and the page shows a “blocked” tag. Reading stays allowed for everyone.

ProofThe owner steps in mid-task.

An owned agent is only yours if you can change its mind. We sent a real Claude Code session on a multi-step web job and interrupted it as the owner, partway through the second read. 1.9 seconds later it was typing the text we asked for into the field we named. It dropped the rest of the plan, left the summary field empty as instructed, and reported what it had done and what it had skipped. The whole run cost about seven cents at API prices.

Getting there took three attempts, and the two that failed are the useful part.

ProofThe agent said no when it should have.

Our first two ways of interrupting failed for a reason that should reassure you. We slipped the message in after a tool call, then sent it as a message during the agent's turn once page text was in the conversation. Claude declined both, saying in its own words that the message “arrived inside a page-read result” and “didn't come from you”.

That is the right behavior for an agent that reads the open web, because a hostile page can write anything it wants into what the agent reads. An owned agent should be suspicious of text that could have come from a stranger.

But it means the owner's voice needs a channel a page cannot forge. The one that worked ends the current turn first, then delivers the owner's message as a fresh turn signed with a marker that exists only in the session's private instructions. A page never sees that marker.

ProofAgents trust each other by default.

We ran mixed teams, Claude and Codex together, on a search task with near-identical decoys. All four runs found the right answer. In all four, the agent that submitted it told us, in its own words, that it had taken a teammate's report without checking. With a decoy or a mistaken teammate, that habit turns one error into a submitted one.

So the layer has to make checking cheap and visible. We built a rule for it: a claim is not reliable until an agent other than the reporter confirms it, and any rejection blocks it.

ProofThis is about safety and visibility, not speed.

We measured it. On a wide search task, three agents finished about 38% faster than one, at about a third more cost. On a short dependent chain, one agent won: faster and cheaper. Letting agents share findings did not make them faster, and on the search task it cost about 65% more tokens.

Owned agents on one page are worth having for what they can do together and for the control the owner keeps. Nobody should sell it as a speedup.

What M9R is, and what it is not.

M9R is small. It is a broker on your machine, a browser extension, and an overlay. Agents you already run connect through the Model Context Protocol. They use the logins and subscriptions you already have, so there are no API keys in any of these tests. In everything described here, M9R's own pieces ran on the owner's machine.

It is not the intelligence. We do not ship a model or an agent. We have tested two, Claude Code and Codex. Any agent that can call MCP tools should be able to connect, including one running on a local model, but we have not run one yet, so we do not claim it. The agents still talk to their own providers. If you run a local model, that traffic stays local because you chose it, not because of us.

What is not done.

  • Two people's agents on two different machines. It is designed and only its core logic exists. We have not run it.
  • Approvals in the overlay, and a stop-everything control. In progress.
  • A real Claude session and a real Codex session working the same live page together in front of the extension. Each has driven these tools on its own, and together only in headless benchmark runs.
  • More than two vendors. Two are verified.
  • The samples are small: six runs per condition for Claude, four for the mixed team, on one test site.
  • The protocol. We are modeling it on the coordination work in the MPAC specification and will publish where it falls short.

Our focus.

The final say stays with the owner. That means seeing who is doing what, stopping all of it, approving the one step that matters, and having a record of what happened. It means owned agents working together without any of them being owned by the place they meet.

If you build or run agents that belong to their owners, we would like to test M9R with you.
