Run it with your own agents

Today this is a developer preview for Windows 10/11. It takes about ten minutes and everything runs on your own PC, with the agent subscriptions you already have. Nothing is uploaded to M9R.

  1. Install Node.js LTS, then clone the repository and run npm ci.
  2. In Chrome or Edge, open chrome://extensions, turn on Developer mode, choose Load unpacked and pick the extensions/browser folder. A Chrome Web Store listing is planned.
  3. Start the local broker: npx tsx scripts/m9r-web-broker.ts. It only listens on your own machine and only accepts the extension ID you give it.
  4. Add the M9R tool server to Claude Code, Codex or OpenCode. Each has a short config block in the install guide.
  5. Ask an agent to open a page. You approve each site once, and risky clicks wait for your yes.

Full steps and every config block: the install guide. Join the waitlist on the home page for the one-click installer and hosted rooms.
